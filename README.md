# 🇧🇷 Português

## 📖 Sobre

Sarah é um bot versátil para Discord desenvolvido utilizando Node.js e Discord.js, criado para atuar como uma assistente virtual dentro de servidores.

O projeto busca unir:

- Automação
- Utilidade
- Música
- Interatividade
- Facilidade de expansão

A Sarah foi pensada para diferentes tipos de comunidades, oferecendo comandos úteis e funcionalidades que ajudam tanto administradores quanto usuários comuns.

---

## 🎯 Objetivo

O objetivo principal da Sarah é fornecer ferramentas úteis e práticas diretamente no Discord, mantendo uma estrutura simples, organizada e fácil de expandir.

O projeto também funciona como uma forma de estudo sobre:

- Bots para Discord
- Sistemas assíncronos
- Eventos
- Organização de aplicações Node.js
- Estruturação de comandos
- Segurança básica em aplicações
